# Spendr-Expense-Tracker

Spendr is a modern mobile expense tracking application built with **React Native** and **Expo**. The application helps users manage their daily expenses efficiently by allowing them to add, edit, delete, and categorize expenses through a clean and intuitive interface.

This project is being developed as part of the **Mobile Technology Bootcamp Capstone Project**.

---

## Features

- User Authentication (Firebase Authentication)
- Add new expenses
- Edit existing expenses
- Delete expenses
- Categorize expenses
- View expense history
- Local data persistence using AsyncStorage
- Responsive and user-friendly interface
- Navigation between multiple screens
- API integration (if applicable)
- Error handling and input validation

---

## Tech Stack

- React Native
- Expo
- JavaScript
- React Navigation
- React Context API
- AsyncStorage
- Firebase Authentication
- Axios / Fetch API

## Installation

Clone the repository

```bash
git clone https://github.com/Nyura-31/Spendr-Expense-Tracker.git
```

Navigate to the project

```bash
cd Spendr-Expense-Tracker
```

Install dependencies

```bash
npm install
```

Start the Expo development server

```bash
npx expo start
```
